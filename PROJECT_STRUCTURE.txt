═══════════════════════════════════════════════════════════
  🚀 Quick Start
═══════════════════════════════════════════════════════════

1. Install dependencies:
   pip install -r requirements.txt

2. Run the game:
   python Main.py

3. Choose game mode (1P or 2P)

4. Select your character

5. Battle!
